# سجل رصد الأسعار (مساعد الرصد)

كل ملف CSV هنا دفعة رصد يدوي من صفحات عامة، تُستورد عبر مسار الخدمة لمصدر «مساعد الرصد»
(`assisted-research-electronics` / `assisted-research-cars`، ترحيل 004) وتدخل **غير موثقة** حتى يعتمدها مشرف
من **اللوحة ← مراجعة الأسعار** بعد فتح الرابط.

## القواعد

- المصدر: صفحة المنتج نفسها لدى الوكيل/الموزع الرسمي أو المتجر الأصلي في السعودية. لا صفحات بحث، ولا مواقع مقارنة
  (موتري، سيارة، هتلاقي، pricena، yaoota...)، ولا لقطات من محركات البحث المخزنة.
- رصد بحجم بشري (فتح الصفحة وقراءة السعر)، بلا جمع آلي يخالف شروط المواقع.
- لا سعر بلا رابط وتاريخ. لا تخمين ولا تعديل. السعر غير المتاح أو غير المطابق لا يُسجَّل.
- المطابقة صريحة في عمود `match`: الموديل + السعة + الذاكرة (إلكترونيات)، أو الموديل + الفئة + السنة + المحرك (سيارات).
- الأسعار بالريال وشاملة ضريبة القيمة المضافة 15% (`vat_included = yes`)، وهي القاعدة في أسعار التجزئة السعودية.

## الأعمدة

`product_id,product_name,store_id,price_sar,list_price_sar,url,observed_at,availability,vat_included,match,notes`

## الاستيراد

```
node scripts/research/ledger-to-sql.mjs data/research/<file>.csv electronics > /tmp/import.sql
```

ثم يُنفَّذ الملف الناتج بدور `postgres` (موصل Supabase). الدالة ترفض الملف المكرر وتتحقق من المصدر والمتجر والمنتج.
