## 2) الكود — لماذا اختفى «الرسم البياني» (مقارنة السوق والسعر العادل)

1. لم يكن في أي نسخة سابقة رسم بياني فعلي؛ «مقارنة السوق» كانت مربعات أسعار (أقل/متوسط/أعلى) + السعر العادل، ومصدر أرقامها
   ملفات ثابتة في الكود (`app/data`).
2. في وضع القاعدة لا يصل للموقع إلا السعر المعتمد الحديث ⇒ مع 0 أسعار معتمدة فرغت المقارنة واختفى القسم.
3. أرقام مقارنة السيارات (119 سعرًا) **منقولة من مواقع مقارنة** (موتري، سيارة، هتلاقي) — مخالف لشرط «عدم نسخ بيانات مواقع المقارنة».

**ما أُصلح:** محرك مشترك (`app/lib/valuation/market.ts`) + رسم بياني حقيقي (`PriceComparison`) في صفحات المنتج والسيارة، متوافق
مع العربية والجوال، يعرض كل مصدر وخط متوسط السوق وخط السعر العادل وعدد المصادر وطريقة الحساب. أُوقف عرض واستخدام الأرقام
المنقولة من مواقع المقارنة (تبقى روابط خارجية فقط).

## 3) مصادر الأسعار — ما يصلح وما لا يصلح

| المصدر | الحالة |
| --- | --- |
| مواقع الوكلاء/الموزعين الرسميين (Apple SA، مواقع العلامات) | ✓ أولوية أولى؛ صفحات عامة تُقرأ بحجم بشري مع رابط وتاريخ |
| جرير | ✓ صفحات المنتج تعرض السعر شاملًا الضريبة ورقم القطعة (تُقرأ مباشرة) |
| إكسترا | ⚠ صفحة المنتج تُحمّل السعر بالمتصفح (JavaScript) فلا يمكن قراءته مباشرة؛ اللقطات المخزنة في محركات البحث غير صالحة (تاريخها مجهول) |
| نون / أمازون | ⚠ لم تُختبر بعد؛ التحديث المنتظم الصحيح لها عبر برامج الشركاء الرسمية (Affiliate/API) لا القراءة الآلية |
| مواقع المقارنة (موتري، سيارة، هتلاقي، pricena...) | ✗ لا ننقل أرقامها؛ روابط مرجعية فقط. الأداة ترفض أي رابط منها |
| لقطات محركات البحث | ✗ أظهرت أسعارًا متضاربة لنفس المنتج (مثال: iPhone 17 256GB بـ 3,799 و4,299) ⇒ لا يُعتمد إلا ما يُفتح مباشرة وقت الرصد |

## 4) قيود معروفة

- قاعدة «3 مصادر مستقلة» + «الأسعار المتطابقة غير مستقلة»: منتجات Apple تُباع غالبًا بسعر موحد لدى كل المتاجر، فسيبقى سعرها
  العادل مخفيًا حتى مع أسعار موثقة، ويُعرض بدلًا منه أقل سعر موثق ومتوسط السوق.
- السيارات الجديدة غالبًا لها موزع رسمي واحد لكل علامة ⇒ السعر الرسمي الموثق متاح، والسعر العادل (3 مصادر) نادر.
- الاعتماد بشري لكل سعر (اللوحة ← مراجعة الأسعار، مع اعتماد مجمّع)، وأي سعر يتجاوز 14 يومًا يختفي تلقائيًا حتى يُرصد من جديد.
