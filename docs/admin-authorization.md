# تصميم صلاحيات لوحة الإدارة (بدون تخزين بعد)

الحالة الحالية: لوحة الاستيراد **معاينة في المتصفح فقط**. لا يوجد نظام دخول
ولا قاعدة بيانات ولا أي نقطة حفظ على الخادم.

## المبادئ

1. **الرفض افتراضيًا.** لا توجد عملية حفظ تعمل بدون هوية مُتحقق منها على
   الخادم وصلاحية صريحة. الوحدة `app/lib/auth/authz.ts` تعيد `null` كهوية حتى
   يُعتمد نظام دخول، فكل حفظ يُرفض الآن.
2. **التحقق داخل كل عملية.** حسب توثيق Next.js 16 (`data-security.md`):
   كل Server Action قابل للاستدعاء مباشرة عبر POST، وحماية الصفحة لا تمتد إليه.
   لذلك كل عملية حفظ تُغلّف بـ `withPermission(...)` وتتحقق بنفسها.
3. **proxy.ts طبقة إضافية فقط.** يخفي `/admin` في الإنتاج (404) ما لم يُضبط
   `TRUEPRICE_ADMIN_PREVIEW=on`، ويضيف `noindex` و`no-store`. لا يُعتمد عليه
   كتفويض.
4. **الهوية من الخادم فقط.** الأدوار لا تُقرأ من المتصفح أو من حقول النموذج.

## الأدوار والصلاحيات

| الصلاحية | viewer | reviewer | admin | تحقق ثنائي |
|---|---|---|---|---|
| import:preview | ✓ | ✓ | ✓ | |
| price:verify / price:reject | | ✓ | ✓ | |
| import:commit | | | ✓ | مطلوب |
| store:approve_alias | | | ✓ | مطلوب |
| catalog:edit | | | ✓ | مطلوب |
| user:manage | | | ✓ | مطلوب |

قواعد إضافية:
- الأدوار غير المعروفة لا تمنح شيئًا.
- الجلسة المنتهية أو بتاريخ غير صالح = مرفوضة.
- **مبدأ العينين:** من رفع السعر لا يوثقه ولا يرفضه بنفسه (`self_review`).

## شكل عملية الحفظ المستقبلية

```ts
// app/admin/import/actions.ts (مستقبلًا — غير موجود الآن)
"use server";
import "server-only";
import { withPermission } from "@/app/lib/auth/authz";

export const commitImport = withPermission(
  "import:commit",
  async (principal, importId: string) => {
    // 1) إعادة قراءة الملف والتحقق منه على الخادم (لا نثق بنتيجة المتصفح)
    // 2) applyImport داخل معاملة قاعدة بيانات
    // 3) تسجيل من نفّذ ومتى في سجل التدقيق
  },
  { resolve: getServerPrincipal } // من نظام الدخول المعتمد لاحقًا
);
```

## ما يحتاج قرارًا قبل التخزين الدائم

- مزود الدخول (مثل Supabase Auth أو غيره) وطريقة التحقق الثنائي.
- جدول المستخدمين والأدوار وسجل التدقيق.
- سياسات صفوف قاعدة البيانات (RLS) كطبقة ثانية خلف `withPermission`.

هذه القرارات مؤجلة حتى موافقتك على مرحلة قاعدة البيانات.
